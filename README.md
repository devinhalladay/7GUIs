converter, flight booker, timer, CRUD, circle drawer and cells — implemented more than once so
the toolkits can be compared side by side.

| --- | --- | --- |
| [`reagent-cljs`](reagent-cljs) | ClojureScript + Reagent | tasks 1–3 |
